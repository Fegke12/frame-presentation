# SPORT / CINEMA — 3 анимационных фильма для урока физкультуры

Три самостоятельных анимированных учебных фильма для рассказа перед классом: **волейбол, баскетбол, футбол**. Подходят для проектора или телевизора. Видеоряд без фонового диктора: **педагог/ученик рассказывает сам**, а фильм автоматически показывает краткие тезисы, площадки, функции игроков, технику, типичные нарушения, комбинации, известных спортсменов и клубы.

Это **анимированная образовательная визуализация** с авторскими SVG-схемами, не запись спортивных матчей, не реальное 3D-видео. Вся графика генерируется кодом в браузере. Внешние изображения и рекламные вставки не загружаются. Google Fonts — необязательный внешний шрифт, при отсутствии интернета используется системный.

## Как запустить

1. Открой `index.html` в браузере (или опубликованную страницу GitHub Pages).
2. Нажми «Волейбол», «Баскетбол», «Футбол» или «Смотреть все три фильма».
3. Смены сцен происходят **автоматически**. В любой момент нажми пробел для паузы, стрелки для перемещения по сценам, `F` для полного экрана, `Esc` для выхода.
4. Текст для ведущего: кнопка **«Сценарий ведущего»** на главной странице, а также `?notes=1&film=volleyball`, `?notes=1&film=basketball`, `?notes=1&film=football`, `?notes=1&film=all`. Открой на телефоне и рассказывай, пока показ идёт на экране. Сценарий можно распечатать.
5. В финале каждого фильма есть экран с заданиями для класса. Поставь фильм на паузу и начинай практику.

## Содержимое

| Раздел | Что демонстрируется |
|---|---|
| Волейбол | 1895 — Уильям Морган; 6×6 и площадка; связующий, атакующие, либеро; подача, приём снизу, передача сверху, удар и блок; 3 касания и нарушения; Гиба, Карч Кирай, Екатерина Гамова, клубы |
| Баскетбол | 1891 — Джеймс Нейсмит; 5×5, очки 1/2/3; амплуа; пас от груди и с отскоком, ведение, бросок; пробежка, двойное ведение, 24 секунды; Джордан, Джеймс, Карри, клубы |
| Футбол | 1863 — FA; 11×11 и поле; позиции; пас внутренней стороной стопы, приём, разворот, удар; офсайд, фолы, анимация атаки; Месси, Роналду, Пеле, клубы |

Анимации — упрощённые учебные схемы, которые показывают последовательность движений. Они **не заменяют личный показ преподавателя** при освоении техники. Темп каждого эпизода рассчитан на короткий живой комментарий, скорость можно менять.

## Техническое устройство

- `index.html` — домашняя страница, экран фильма и элементы управления.
- `cinema.css` — адаптивный дизайн и переходы.
- `content.js` — контент и слова ведущего для каждой сцены (можно менять без правки кода визуализации).
- `cinema.js` — SVG-площадки, анимации людей и мяча, смена сцен, пауза, навигация, полный экран, режим сценария.
- `narrator.md` — текст выступления, который можно распечатать отдельно.
- `classic.html` — резервная копия прежнего интерактивного урока.

**Никаких сборщиков, npm, серверного кода или ключей API:** GitHub Pages публикует сайт прямо из этих файлов. Программа работает на компьютере локально без сети (кроме загрузки внешнего шрифта).
