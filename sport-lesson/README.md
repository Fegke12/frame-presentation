# SPORT / LAB — Три игры. Один урок.

Интерактивный сайт для проведения **45-минутного урока физкультуры**. Тема: баскетбол, волейбол, футбол. Без npm, сборщика и сервера: достаточно открыть `index.html` в браузере или опубликовать на GitHub Pages.

## Что внутри

- Современная адаптивная главная страница со схемой занятия.
- Интерактивные вкладки с историей трёх игр, техникой базовых передач и векторными схемами.
- **Режим урока**: 7 этапов, 45 минут, таймер для каждого этапа, инструкция для класса, заметка ведущему.
- **Крупный таймер** для проектора, пауза, сброс, переход между этапами, необязательный звуковой сигнал.
- Короткий квиз из 3 вопросов с проверкой и объяснениями.
- Работа без API и регистрации. Шрифты Google Fonts необязательны — при отсутствии сети используются системные.

## Управление в режиме урока

- **Пробел** — старт / пауза таймера.
- **← / →** — предыдущий / следующий этап.
- **F** — переключить полноэкранный режим (в браузере также можно использовать F11).
- **M** — звук вкл./выкл.
- **Esc** — выйти из крупного таймера или закрыть режим урока.
- Кнопка **Крупный таймер** оставляет на экране большое время и короткое задание.

Таймер **не переключает этап автоматически**: ведущий должен убедиться, что класс готов, а затем нажать «Следующий этап». После истечения времени звучит короткий сигнал (если звук включён и поддерживается браузером).

## Публикация в отдельном репозитории GitHub Pages

1. Создай **публичный** репозиторий, например `sport-lab-lesson`.
2. Загрузи содержимое этой папки **в корень репозитория**: `index.html`, `style.css`, `app.js`, `.nojekyll`, `README.md`.
3. Открой **Settings → Pages**.
4. Выбери **Build and deployment → Source: Deploy from a branch**, ветку `main`, папку `/(root)` и нажми **Save**.
5. После публикации ссылка будет вида `https://ТВОЙ_НИК.github.io/sport-lab-lesson/`.

Если папка `sport-lesson` хранится **внутри другого репозитория**, в настройках Pages этого репозитория выбери публикацию из `main /(root)`. Тогда сайт будет доступен по адресу `https://ТВОЙ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/sport-lesson/`. GitHub Pages не позволяет выбрать произвольную вложенную папку вместо `/` или `/docs` в настройках branch deploy.

## Редактирование

- `app.js`: массив `stages` содержит этапы урока, время, задания и подсказки. `sports` — исторические справки и техника. `quizzes` — вопросы.
- `style.css`: цвета, типографика, адаптивные стили и экран проектора.
- `index.html`: разметка разделов.

## Требования к безопасности

Упражнения проводятся **под присмотром преподавателя**, на подходящей безопасной площадке, с исправным инвентарём. Не увеличивай нагрузку или дистанцию за счёт техники. Дай участникам отдых и воду по необходимости. Содержание сайта — план занятия, а не замена инструктажу преподавателя.

## Исторические справки

- Баскетбол — Джеймс Нейсмит, 1891 год.
- Волейбол — Уильям Дж. Морган, 1895 год.
- Футбол — основание Английской футбольной ассоциации и оформление единых правил, 1863 год (различные игры с мячом существовали намного раньше).
